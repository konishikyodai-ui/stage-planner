# 舞台図エディタ（筑波大学吹奏楽団）

ホールから受け取った平面図の上に、椅子・譜面台・山台・楽器を実寸（mm）で配置する舞台図作成ツールです。
配置から必要物の数量を集計し、PDF / PNG で出力できます。3D表示で客席からの見え方や、各席からの見え方も確認できます。

- **使う人向けの説明**：[help.html](help.html)（アプリ右上の「使い方」からも開けます）
- **公開URL**：`https://<アカウント名>.github.io/<リポジトリ名>/`（GitHub Pages を有効にしたあとに決まります）

サーバーやデータベースは使いません。HTML / CSS / JavaScript だけで動くため、GitHub Pages などに置くだけで公開できます。
作成した舞台図は各自のブラウザ内（IndexedDB）と、「ファイル保存」で書き出す `.stage.json` にだけ保存されます。
そのため、アプリを公開しても図面データが外部に送られることはありません。

## 主な機能

- 図面読込（PNG / JPEG / PDF のページ選択）、透明度の調整、背景のロック
- 2点指定による縮尺合わせ（1間・半間・3尺などのプリセットあり）と縮尺確認（誤差率の表示）
- シンボルライブラリ：指揮台、椅子、譜面台、山台（6×3尺ほか）、鍵盤打楽器、ティンパニ 23/26/29/32"、そのほかの打楽器、コントラバス、ピアノ、注釈
- 山台一括配置（列ごとに種類・枚数・向き・段高を指定）、円弧・吹奏楽テンプレート、横一列配置。いずれもグループとして配置し、解除も可能
- 必要物一覧（表示中 / すべて、パート別の人数、コピー・CSV出力）
- PDF / PNG 出力（A4・A3、縦・横、1:50・1:100・用紙に合わせる、スケールバーと表題欄付き）
- 3D表示（俯瞰、この席から見る、奏者アバター）
- 自動保存、プロジェクトファイルの保存と読込、元に戻す / やり直し
- タッチ操作（2本指での移動・ピンチ拡大、選択時の操作バー）、オフライン対応（Service Worker）、ホーム画面への追加

## GitHub Pages で公開する手順

1. 楽団名義の GitHub アカウント（または Organization）で、新しいリポジトリを作成します（例：`stage-planner`、Public）。
   担当者が卒業しても引き継げるよう、個人アカウントは避けてください。
2. このフォルダでリモートを登録して送信します。
   ```bash
   git remote add origin https://github.com/<アカウント名>/stage-planner.git
   git push -u origin main
   ```
3. GitHub のリポジトリで **Settings → Pages** を開き、**Build and deployment** の Source を「Deploy from a branch」、
   Branch を `main` / `/ (root)` にして保存します。
4. 1〜2分後に `https://<アカウント名>.github.io/stage-planner/` で開けるようになります。このURLを楽団内に共有してください。

> ホールから受け取った図面や、作成した `.stage.json` はこのリポジトリに入れないでください（`.gitignore` で除外しています）。
> リポジトリは公開されるため、図面は楽団の共有ドライブで管理します。

## 更新するとき

1. ファイルを修正し、下記「ローカルで確認する」の手順で動作を確認します。
2. **`sw.js` の `VERSION` を新しい値に変更します**（例：`'2026-10-05a'`）。
   変更しないと、利用者の端末に古い版のキャッシュが残ります。
3. ファイルを追加・削除した場合は、`sw.js` の `ASSETS` 一覧も合わせて更新します。
4. コミットして `git push` すると、数分で公開版に反映されます。
   利用者は、インターネットにつながった状態でアプリを開き直すと新しい版になります。

## ローカルで確認する

`index.html` をダブルクリックしても動きます。ただし、Service Worker（オフライン対応）は `http://` で開いたときだけ有効です。
これも含めて確認するときは、このフォルダで次のコマンドを実行し、http://localhost:8765/ を開きます（Windows、追加インストール不要）。

```bash
powershell -ExecutionPolicy Bypass -File tools/serve.ps1
```

## フォルダ構成

| パス | 内容 |
|---|---|
| `index.html` / `style.css` | 画面の構成と見た目 |
| `help.html` | 使い方ページ |
| `js/core.js` | 状態・配置物の種類定義（寸法はここ）・履歴・幾何計算 |
| `js/render.js` | 2D描画（画面と出力で共通） |
| `js/editor.js` | マウス・タッチ・キーボード操作、モード管理 |
| `js/tools.js` | 山台一括・円弧（吹奏楽テンプレート）・横一列、サンプル配置 |
| `js/panels.js` | ライブラリ、編集パネル、必要物一覧、レイヤー、選択時の操作バー |
| `js/io.js` | 図面読込、縮尺合わせ、保存・自動保存、PDF / PNG 出力 |
| `js/view3d.js` | 3D表示 |
| `js/main.js` | 起動処理、ツールバー、Service Worker の登録 |
| `sw.js` / `manifest.webmanifest` / `icons/` | オフライン対応とホーム画面への追加 |
| `vendor/` | 同梱ライブラリ（PDF.js、three.js）。詳細は [vendor/README.md](vendor/README.md) |
| `tools/serve.ps1` | ローカル確認用の簡易サーバー |

よく変更する箇所：

- 配置物の寸法・種類の追加：`js/core.js` の `SP.TYPES`
- 吹奏楽テンプレートの並び：`js/tools.js` の `SP.ARC_TEMPLATES`
- 略称ボタン：`js/core.js` の `SP.PART_LABELS`
